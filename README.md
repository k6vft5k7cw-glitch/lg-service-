# LG Service — site web

Site vitrine de LG Service (débarras, location de bennes, achat et vente de métaux à Morestel).

- `index.html` : page unique (accueil, services, bennes, débarras, métaux, à propos, contact)
- `assets/css/style.css` : styles
- `assets/js/main.js` : animations (GSAP + ScrollTrigger, défilement fluide Lenis), menu, formulaire
- `assets/img/` : logo et photos

Site statique, sans build : ouvrir `index.html` ou le servir avec n'importe quel hébergeur.
Le déploiement sur GitHub Pages est automatique à chaque push sur `main`
(`.github/workflows/pages.yml`).
